# Antools — вёрстка учебного макета

Работу выполнил Никита Реньш для [Abanking Education](https://education-student.abanking.ru/).
Форк [стартового шаблона](https://github.com/artsofte-ts-2022-2023/Abanking-education-html).

## Макет

[Исходный макет в Figma](https://www.figma.com/design/jFj70BijeNOjaCI9N6wZZf/For-univrseity-course-landing).
Перенесены все три блока фрейма Desktop размером 1440 × 2510: первый экран, каталог из шести инструментов и блок брендов. Изображения выгружены из макета, шрифты Poppins хранятся локально в `src/assets/fonts/`; лицензия шрифта приложена.

## Запуск

Нужны Node.js 20.19+ (проверено на Node.js 24) и npm.

```sh
npm ci
npm start
```

Откроется страница `http://127.0.0.1:4173`. Для сборки:

```sh
npm run build
```

Готовые файлы находятся в `dist/`.

## Реализация

HTML, SCSS, JavaScript, Webpack. Имена классов следуют БЭМ: `tool-card`, `tool-card__title`, `tool-card_featured`, `tool-card__action_active`. Элементы именуются от блока; цепочек элементов нет.

- Поиск фильтрует инструменты по названию и описанию.
- Меню Categories фильтрует по назначению.
- Кнопки сердца сохраняют избранное, кнопки папки добавляют инструмент в My Collections. Выбор сохраняется в браузере.
- Load more добавляет три отдельные карточки ресурсов Figma, VS Code и Notion.
- Visit, логотипы брендов, социальные ссылки и Blog ведут на соответствующие внешние страницы.
- Login и Sign Up открывают формы локального профиля. Данные сохраняются только в этом браузере; серверной регистрации и отправки формы нет. Профиль можно удалить из окна формы.
- Поддерживаются клавиатурная навигация, Escape, подписи полей, состояния переключателей и уменьшение анимации. На узких экранах карточки перестраиваются в две или одну колонку.
